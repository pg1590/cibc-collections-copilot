# Local source material

Organizer PDFs and their text extracts are retained locally, outside the public repository. The source deck is marked Confidential. Add the authorized source files locally before reproducing an agent review.

Available local extracts:
- problem-statement.txt: current submission and judging instructions.
- challenge-brief.txt: supplementary challenge deck.
- data-dictionary-about.txt: overview, scale, formats, snapshot and identity-key context.

The supervisor authorizes the team to choose target tables, columns and relationships, documented in ../data-model.md. All incoming field-level source mappings remain TBC.
